# Criminal Network Intelligence Platform

An investigative intelligence platform for analyzing criminal networks using:

- Case management
- Evidence processing
- Entity extraction
- Relationship extraction
- Graph analytics
- CDR analysis
- Blockchain analysis
- AI-assisted risk analysis
- Investigation timelines
- Intelligence reports

## Architecture

Frontend: React + Vite

Backend: Spring Boot

AI Service: Python + FastAPI

Databases: PostgreSQL + Neo4j

Deployment: Docker
